# persian Project

This project is a modern banking and consultancy website focused on clean UI/UX, responsiveness, and smooth user experience. The goal is to provide banking-related services and consultations through a clean and user-friendly interface.

---

## Technologies and Libraries

- **Next.js 14**: Main framework for building React-based web applications with SSR.
- **Tailwind CSS**: Utility-first CSS framework for fast and responsive design.
- **Framer Motion**: For smooth and interactive animations across pages and forms.
- **Swiper**: For creating responsive sliders and carousels.
- **React Hook Form**: Efficient and flexible form management library.
- **Zod**: Schema-based validation for forms.
- **Lucide-react**: Modern, lightweight icon library for UI elements.
- **Shadcn/UI or Material UI (optional)**: Recommended for professional UI and ready-to-use components.

---

## Features

- **Component-based structure**: All sections are divided into reusable components for maintainability and scalability.
- **Responsive design**: Fully responsive across devices, from mobile to desktop.
- **Smooth animations**: Various components animate using Framer Motion when entering the viewport.
- **Dynamic and validated forms**: Forms are powered by React Hook Form and validated with Zod.
- **Modern icons**: Lucide-react icons are used for all UI elements.
- **Clean and maintainable code**: Best practices for React and TypeScript are followed throughout the project.
